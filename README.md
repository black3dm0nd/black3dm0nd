# black3dm0nd

## Security Researcher | Red Teaming | Offensive Security

Security Researcher focused on red teaming, offensive security, adversary simulation, and practical vulnerability research. Work spans infrastructure, web applications, APIs, cloud environments, mobile applications, desktop applications, wireless networks, social engineering, and emerging AI security risks.

Approach shaped by offensive security practice and red team methodology: understand the environment, identify meaningful attack paths, validate impact with evidence, and communicate findings in a way that helps technical teams reduce risk. Primary areas of interest include the space between offensive execution and defensive improvement, where exploitation, detection, and remediation meet.

Operating under the public research identity **black3dm0nd**, with published offensive security research, operator notes, lab work, and tooling for authorized security testing.

---

## Expertise

- **Red Team Operations:** adversary simulation, attack path development, objective-based testing, control validation, and post-exploitation decision-making.
- **Network Penetration Testing:** internal and external infrastructure assessments, Active Directory attack paths, privilege escalation, lateral movement, segmentation testing, and exposure validation.
- **Web Application Security:** authentication, authorization, business logic flaws, injection vulnerabilities, client-side exposure, chained exploitation, and secure remediation guidance.
- **API Security Testing:** access-control weaknesses, object-level authorization flaws, authentication flows, data exposure, rate-limit abuse, and integration risk.
- **Mobile Security:** Android and iOS application testing, traffic analysis, local storage review, authentication handling, and backend interaction testing.
- **Cloud Security:** security assessments across AWS, Microsoft Azure, and Google Cloud Platform, with focus on identity, configuration, exposed services, and cloud attack paths.
- **Desktop Application Testing:** Windows and macOS application assessment, local attack surface analysis, traffic inspection, credential handling, and business logic review.
- **Social Engineering:** phishing and vishing engagements designed to validate human-layer controls, awareness, and response capability.
- **Wireless Security:** WiFi security assessments, configuration review, credential exposure, and access control validation.
- **AI Security Testing:** assessment of AI-enabled systems, prompt and workflow abuse cases, data exposure risks, and security control validation.
- **Source Code Review:** security-focused code review, vulnerability discovery, exploitability assessment, and remediation support.

## Open Source Security Tools

- **[GhostEye](https://github.com/black3dm0nd/ghosteye)**: External reconnaissance for a domain's mail, identity, hosting, web stack, and public exposure. Passive by default, with active modules enabled explicitly for scoped assessments.
- **[m365hunt](https://github.com/black3dm0nd/m365hunt)**: Microsoft 365 and Entra ID reconnaissance for account enumeration, tenant discovery, federation analysis, and username-format detection using public authentication signals.
- **[jsrecon](https://github.com/black3dm0nd/jsrecon)**: Client-side attack-surface mapper for web security testing, focused on JavaScript secrets, endpoints, parameters, source maps, DOM-XSS leads, S3 buckets, and developer comments.
